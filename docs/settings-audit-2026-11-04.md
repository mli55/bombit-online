# 4399 玩法设置核验（2026-11-04）

后续实现已修正角色移速、连锁爆炸、道具分布、AI 决策和计分，见 [五类规则对齐](classic-parity.md)。本文保留修改前的核验记录，表中的“当前”指当时的基线。

结论：当前版本并非所有设置都与 4399 一致。普通炸弹引信、普通爆炸伤害时长公式、冰冻/减速时长和开阔区域冰火柱时序已对齐；火箭爆炸、地雷隐藏、护盾、移动速度、道具概率、上限、AI 和部分碰撞规则仍有差异。

本次基于 `765bafa` 核验，并补修初始生命被资源加载覆盖的问题。除该已要求的生命修复外，本次不调整其他玩法。下文“当前”指本地实际运行的这份代码，不代表已检查远端部署版本。

## 炸弹、火焰与技能时间

| 项目 | 4399 原版 | 当前实现或本次测量 | 结论 |
| --- | --- | --- | --- |
| 普通炸弹引信 `BOMB_TIMER` | 60 帧 = 1.714286 秒 | 103 个模拟帧 = 1.716667 秒 | 时长已对齐 |
| 普通爆炸伤害窗口 | 从中心引爆算起 `(威力 + 10) / 35` 秒 | 同公式；威力 1 实测 0.316667 秒，威力 5 实测 0.433333 秒 | 同威力下时长已对齐 |
| 空地火焰传播 | 每帧一格，即每格 28.571 ms | 按距离乘以 28.571 ms 安排回调 | 名义时序已对齐，存在帧量化 |
| 炸箱子、连锁引爆 | 火焰逐格到达后产生效果 | 非空格走同步 `checkNotEmpty`，可在传播到达前炸箱/引爆 | 不一致 |
| 伤害结束后的可见火焰 | 另有 5 帧无伤害淡出，约 0.143 秒 | 火焰与伤害同时清除 | 不一致；画面保留时间更短 |
| 地雷、手榴弹落点伤害 | 10 帧 = 0.285714 秒 | `WeaponExplosion` 使用同目标值；地雷实测在 0.300 秒内清除 | 时长已对齐 |
| 火箭落点伤害 | 10 帧 = 0.285714 秒 | **实测 0.500 秒**，独立 `Rocket.update` 仍硬编码 500 ms | **不一致** |
| 冰冻 `FROZEN_TIME` | 最后一次接触冰之后 300 帧 = 8.571429 秒 | 515 个模拟帧 = 8.583333 秒 | 名义时长已对齐；接触判定仍不同 |
| 减速 `SLOW_TIME` | 600 帧 = 17.142857 秒 | 1029 个模拟帧 = 17.150 秒 | 时长已对齐 |
| 开阔区域冰柱/火柱 | 第 4/8/12 帧生成三格，第 49 帧清理，1.4 秒 | 同时序；实测 1.400 秒 | 开阔区域已对齐 |
| 冰火柱受阻时序 | 遇到阻挡将时间轴计数跳到 12，会提前进入消退阶段 | 自激活起统一等到 1.4 秒 | 不一致 |
| `TIME_FIRE_ON`、`TIME_ICE_ON` | 由上述帧逻辑决定 | 配置仍显示 1500 ms，但实际被 `Columns.update` 覆盖为上述逻辑 | 不能只看配置文件 |
| 地雷隐藏 `TIME_TO_HIDE_MINE` | 时间轴第 60 帧移除最后一个可见图形并停止；约 1.7 秒 | 配置 3500 ms，实测 211 帧 = 3.516667 秒 | 不一致 |
| 护盾消耗后的无敌 | 60 帧 = 1.714286 秒 | 实测 2.000 秒 | 不一致 |
| 开局闪烁/保护 `INITIAL_BLINKING_TIME` | 60–63 帧，约 1.714–1.800 秒 | 2000 ms | 不一致 |
| 结算画面切换 | 默认 5500 ms，也支持按键跳过 | 5000 ms | 不一致 |

特别更正：此前 `classic-timing.md` 把“手榴弹 / 火箭”合并成一项，容易误以为二者都已改成 10 帧。火箭没有经过 `WeaponExplosion`，所以原先的修改没有覆盖它。

地雷隐藏的时间轴：第 10/20/30/40/50/60 帧移除图形，第 15/25/35/45/55 帧重新显示，第 60 帧停止且不再显示。第 60 帧的位置不应当被当成已实测精确 60 个经过帧；这里仅给出约 1.7 秒的源代码时间轴结论。

## 初始生命修复与复现

`765bafa` 在补丁加载时设为 1，但随后 `PreloaderState.checkBalanceData` 又从原版 `balance.json` 写回 3。浏览器核验得到主菜单设置 3、单人开局 `[3,1,1,1]`，所以此前仅凭语法检查和单元测试断言“单人已改为 1”不充分。

本次在原版配置读取完成后再次设置初始生命为 1，保留其他配置的加载。修复后实际主菜单设置为 1，单人及联机开局均为 `[1,1,1,1]`。新增覆盖配置加载顺序的回归测试。未改变拾取生命道具和跨关卡存档行为。

复现命令（先构建并启动服务器，Playwright/Chrome 路径通过环境变量配置）：

```sh
npm run check
npm test
npm run build
node scripts/qa-classic.mjs
node scripts/qa-settings.mjs
```

本次语法检查、构建和 64 项单元/网络测试通过；真实引擎经典时序和设置核验通过。仍待如需完整对齐时逐项处理上述差异，并覆盖交叠爆炸、阻挡、连锁、技能飞行及暂停边界；本次核验不能证明所有游戏事件等价。
